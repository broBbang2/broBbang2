## 🚀 Featured Project

### 🍶 Choice — 취향 기반 술 추천 서비스

> 입문자를 위한 AI 대화형 술 추천 웹 애플리케이션

ChatGPT와 대화하며 취향을 설명하면 어울리는 술을 추천받고,  
커뮤니티 피드에서 다른 사람들의 추천도 둘러볼 수 있습니다.

**주요 구현 사항**

- OpenAI API를 활용한 대화형 추천 플로우 설계
- Supabase PostgreSQL + GIN 인덱스로 태그 검색 최적화 (`2007ms → 262ms`)
- `Promise.all` 병렬 쿼리로 첫 진입 초기 로딩 시간 단축
- Zustand 기반 클라이언트 상태 관리 (추천 결과, 즐겨찾기)
- shadcn/ui + Tailwind CSS v4 로 반응형 UI 구성

**Stack:** `Next.js 16` `React 19` `TypeScript` `Tailwind CSS v4` `Supabase` `OpenAI` `Zustand`

## 🚀 Featured Project

### 🍶 Choice — AI 기반 취향 맞춤 주류 추천 서비스

> 술을 처음 접하는 사용자가 대화를 통해 자신에게 맞는 술을 찾을 수 있도록 설계한 서비스

#### 주요 기능

- OpenAI API 기반 대화형 추천 시스템
- 사용자 취향 분석 후 맞춤형 술 추천
- 추천 결과 저장 및 즐겨찾기 기능
- 커뮤니티 피드를 통한 추천 공유

#### 성능 개선

- PostgreSQL GIN 인덱스 적용
  - 태그 검색 속도 개선
  - **2007ms → 262ms (약 87% 감소)**

- Promise.all 병렬 처리
  - 초기 데이터 로딩 시간 단축
  - 사용자 체감 성능 향상

#### 기술 스택

`Next.js`
`React`
`TypeScript`
`Tailwind CSS`
`Supabase`
`OpenAI`
`Zustand`
